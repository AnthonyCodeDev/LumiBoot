Windows 10 x86 — image disque NON fournie
=========================================
Aucun disque n'est versionné dans ce dossier.

En local :
  1. placer votre propre disque RAW ici : disk.img
  2. régénérer le manifeste : pnpm assets:windows10:prepare

manifest.json décrit le disque (taille, démarrage BIOS, URL
/images/windows-10-x86/disk.img) ; il ne contient aucun chemin local.

# ADR 0002 — v86 and Debian 12 i386

- Status: accepted
- Date: 2026-10-14

## Context

v86 emulates 32-bit x86 in WebAssembly. Debian 13 no longer ships an i386 kernel or installer.

## Decision

Engine `v86@0.5.471`, loaded lazily by `@lumiboot/provider-v86` and declared in `packages/catalog/src/engines.ts`. Target: Debian 12 Bookworm i386. Manifests are validated in `@lumiboot/vm-assets`; binaries stay outside Git.

## Consequences

- CLI, X11/Openbox and XFCE variants each get an image and a profile. `running` follows `LUMIBOOT_GUEST_READY` or `LUMIBOOT_DESKTOP_READY`.
- No hardware virtualization: Windows 10/11 x64 and modern macOS are excluded (revised 2026-11-11, see below).

## Revision (2026-11-11)

The 64-bit exclusion above applied to v86, which emulates 32-bit x86 only. The separate `v64`
engine now serves x86-64 guests in the browser without hardware virtualization: **Windows 11 x64**
and **macOS Lion 10.7.5 x64** boot inside LumiBoot ([`../v64.md`](../v64.md),
[`../systems.md`](../systems.md)). Still excluded: 64-bit guests on v86, and **Apple Silicon macOS**
(Sequoia), which needs an ARM64 engine that is not integrated — a roadmap item, not a macOS
limitation. The decision above is otherwise unchanged.
